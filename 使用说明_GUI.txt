一、怎么用
----------------------------------------
1. 双击 PDF转MD.exe（首次启动会先自检，约几秒）。
2. 首次运行会弹窗显示：
   · 本机 CPU / 内存 / 显卡 / 磁盘
   · 建议并发数（按可用内存和物理核数算）
   · 是否使用独显
   · 缺少哪些依赖、要下载多大
3. 在弹窗里确认“安装根目录”（Python 环境和模型都装在这里），
   点“开始安装并配置”。下载完成后即可正常使用。
4. 主界面：左侧“添加 PDF / 添加文件夹”，右侧选输出位置，点“开始转换”。
5. 完成后双击列表行打开 md；右键可打开所在文件夹、QA JSON、重新转换。

二、首次安装会下载什么
----------------------------------------
基础（必需）：
  · Python 3.12 环境 + MinerU + pymupdf/pdfplumber   约 0.8 GB
  · 版面/表格/OCR 基础模型                            约 0.8 GB
可选（推荐）：
  · 增强补漏 VLM 模型                                 约 1.2 GB
  · NVIDIA CUDA 后端（勾选“使用独显”时）             约 3.5 GB

全部装好约 3–6 GB（取决于是否装 GPU）。安装目录由你在弹窗里选择，
支持中文路径（例如 D:\环评工具\PDF2MD）；仍建议不要装进 Program Files，避免权限问题。

三、并发与显卡
----------------------------------------
· 并发数按“可用内存 ÷ 6 GB”和物理核数自动建议，最大 3。
· 每份转换占 5–6 GB 内存；内存不足时程序会提示降低并发。
· 有 NVIDIA 显卡且显存 ≥ 8 GB 时建议勾选“使用独显”；
  没装 CUDA 后端时程序会自动回退 CPU，不会失败。
· 没有独显就用 CPU，basic 档约 3–4 秒/页。

四、输出
----------------------------------------
· 默认输出到 PDF 同目录下的 md输出\ 文件夹。
· 也可以指定统一输出目录；勾选“保留文件夹层级”可保持原目录结构。
· 每份生成：
    文件名.md        正文，带 <!-- p123 --> 页码锚点
    文件名_qa.json   质量报告（平均/最低覆盖率、表格数、漏字页）
· 少于 20 页的 PDF 默认跳过（可在界面取消勾选）。

五、命令行/API 仍然可用
----------------------------------------
PDF转MD.exe capabilities
PDF转MD.exe version
PDF转MD.exe convert "某报告.pdf" -o "输出目录"
PDF转MD.exe batch "报告目录" -o "输出目录" --pattern 报告书 --workers 2
PDF转MD.exe serve --host 0.0.0.0 --port 8765 --token 你的密钥

双击默认进图形界面；带参数运行仍是原来的命令行行为。

六、常见问题
----------------------------------------
Q 双击后一闪而过？
  必须把 PDF转MD.exe 和 _internal\ 放在同一目录，不能只拷 exe。

Q 安装失败？
  弹窗会显示失败步骤和日志。优先检查网络/磁盘空间；
  换镜像重试即可，已完成的步骤不会重下。

Q 杀毒软件报警？
  PyInstaller 程序常被误报，选择“允许/信任”。

Q 转换很慢？
  扫描件/复杂表格会慢；basic 档约 3–4 秒/页。
  勾选 standard 或漏字页补跑会明显变慢，但质量更好。

Q 中文路径能用吗？
  可以用。输入 PDF、输出目录、Python 环境和模型目录都支持中文，
  已实测中文路径下的基础与增强模型转换。若个别第三方引擎仍报
  Unicode 错误，再到“安装/修复”里换一个英文路径即可。

七、安全
----------------------------------------
· 默认全程本地处理，不上传任何文件。
· 只有你自己在弹窗里确认安装依赖时才会联网下载。
· 程序不保存任何密钥；API 模式建议加 --token 并只在局域网使用。


八、给 AI / 自动化程序调用
----------------------------------------
本包自带完整调用说明，其他 AI 拿到后按顺序读：

  1. skill\pdf-to-md-eia\SKILL.md        ← 先读这个（触发条件、GPU 判断、质量红线）
  2. AI调用说明.md                        ← 最短调用步骤
  3. API接口.md                            ← HTTP 字段
  4. skill\pdf-to-md-eia\references\      ← api.md / gui.md / gpu.md / installation.md
  5. AI调用示例.py / skill\...\scripts\pdf2md_client.py  ← Python 客户端

启动服务：
  PDF转MD.exe serve --host 0.0.0.0 --port 8765 --token 你的密钥

调用顺序：
  GET  /capabilities   ← 必须先看，按 recommended 传 device/tier
  POST /convert        ← 服务器本地路径，或 multipart 上传
  GET  /jobs/<id>      ← 轮询
  GET  /jobs/<id>/download  ← 取 md

单机命令行：
  PDF转MD.exe capabilities
  PDF转MD.exe convert "某报告.pdf" -o "输出目录"
  PDF转MD.exe batch "报告目录" -o "输出目录" --pattern 报告书 --workers 2

注意：
  · 不要调用内部命令 _job（那是 GUI 用的）
  · 不要在公网暴露 serve；内网也要设 token
  · 先看 QA 的 min_page_recall，低于 0.90 建议抽检


九、支持的文件格式
----------------------------------------
  · PDF   —— 原有高质量链路（MinerU + 表格重建 + 漏字页补跑）
  · DOCX  —— 原生解析，保留标题、段落、表格（表格用 HTML 保留合并单元格）
  · XLSX  —— 按工作表转 Markdown 表；合并单元格会填入左上角的值
  · DOC / XLS —— 旧版二进制格式，需要 LibreOffice：
      第一次添加 .doc/.xls 时程序会询问，确认后自动用 winget 安装
      LibreOffice（约 350 MB，可能弹 UAC）；也可以从菜单
      “环境 → 安装旧版 DOC/XLS 支持”手动触发。
  说明：
  · 少于 20 页的跳过规则只对 PDF 生效；Office 文件不按页数跳过。
  · DOCX/XLSX 不需要 MinerU，速度比 PDF 快很多。
  · Office 文件不生成页码锚点；QA 里 pages 为 0，tables_md/sheets 等字段仍然有效。


十、离线使用
----------------------------------------
可以，但要区分“转换”和“首次安装”：

· 转换本身完全离线
  - PDF：本地 MinerU 模型，不联网
  - DOCX/XLSX：本地 Python 解析，不联网
  - DOC/XLS：本地 LibreOffice，不联网
  - 不上传文件、不调用云端服务
  - API 模式只需局域网，不需要外网

· 第一次安装依赖需要联网
  - Python 3.12 / MinerU / pymupdf / pdfplumber
  - 基础模型 + 增强模型
  - NVIDIA CUDA 后端（勾选独显时）
  - LibreOffice（第一次转旧版 DOC/XLS 时）
  装完之后，日常转换可以完全断网。

· 离线部署建议
  1. 在一台有网的机器上安装，安装目录选成和离线机器完全相同的路径
     （例如都选 D:\PDF2MD_runtime）。
  2. 安装时把需要的模型/LibreOffice/CUDA 都装好。
  3. 把下面三样按原路径拷到离线机器：
       PDF转MD_桌面版\        （exe 和 _internal）
       D:\PDF2MD_runtime\      （mineru_env + mineru_home）
       如果模型装在其他盘，也按原路径一起拷。
  4. 不要只拷 PDF转MD.exe：exe 里不含 MinerU 和模型。

  注意：Python 环境里的脚本记录的是绝对路径，换盘符/换目录后可能失效；
  离线部署时尽量保持安装路径一致。如果离线机器没有 Python，
  也不能只靠拷 exe 完成安装。

· 需要真正的“离线安装包”？
  目前还没有一键离线包。可以另外做一个更大的离线部署包：
  把 uv、Python、MinerU 的 wheel、模型、LibreOffice 安装包一起打包，
  体积约 4–6 GB。需要的话告诉我，我再做。
