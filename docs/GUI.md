# 桌面版使用说明

## 主界面

![主界面](images/gui-main.png)

左侧是文件队列，右侧是输出设置、档位/设备/并发、开始/停止、进度和日志。

### 添加文件

- 「添加 PDF…」：支持 PDF / DOCX / DOC / XLSX / XLS
- 「添加文件夹…」：递归扫描这些后缀
- 也可以把文件直接拖到 exe 上

### 输出

- **源文件旁 md输出**：每份文件在所在目录下生成 `md输出\文件名.md`
- **指定目录**：统一输出；勾选“保留文件夹层级”可保留原目录结构
- 同名文件会自动加父目录名/序号，避免覆盖

### 档位与设备

| 选项 | 说明 |
|---|---|
| `basic` | 推荐；CPU 约 3–4 秒/页 |
| `standard` | 更慢，但漏字更少；可用于疑难报告 |
| `advanced` | 最慢，质量最高 |
| `cpu` | 没有独显时使用 |
| `cuda` | 需要 `backend_ready=true`；未就绪会自动回退 CPU |
| 并发 | 按可用内存和物理核数建议，最大 3；单文件 ≥20 页自动拆页并行 |

### 保存任务 / 加载任务

长任务可以中断后继续：

1. **文件 → 保存任务…**（Ctrl+S）：把队列、输出设置、档位/设备/并发，以及每个文件的状态存成 `.json`；
2. 中断后重新打开程序，**文件 → 加载任务…**（Ctrl+L）选择这个文件；
3. 已经生成 md 的文件显示「完成」，不会重跑；未完成的显示「等待」，点「开始转换」继续；
4. 原文件被移动或删除的，会标记为「文件缺失」，需要重新添加。

加载任务时，已完成的文件优先按“输出 md 是否存在”判断；即使勾了“覆盖已存在的 md”，加载后也不会重跑，只有右键“重转选中”才会清掉完成标记。

### 开始 / 停止

- 点「开始转换」后，列表逐行更新状态、用时、平均覆盖率、输出路径
- 「停止」会杀掉当前子进程，已完成的不受影响
- 关闭窗口时如果有任务，会确认后停止并清理进程

### 窗口恢复

- 最小化后从任务栏恢复；首次向导如果开着，会随主窗口一起回来。
- 如果窗口跑到屏幕外：**文件 → 重置窗口位置/大小**。
- 最小化状态下关闭不会保存错误尺寸，重新打开仍是原来的大小。

### 结果

- 双击行：打开生成的 `.md`
- 右键：打开结果 / 所在文件夹 / QA JSON / 重新转换 / 移除
- 少于 20 页的 PDF 默认跳过（可取消勾选）；Office 文件不按页数跳过

## 首次运行自检

![首次运行](images/gui-wizard.png)

首次启动会：

1. 读取 CPU 物理核/线程、内存、显示适配器（NVIDIA / AMD / Intel）、安装盘空间；
2. 计算推荐并发；AMD / Intel 集显会明确提示“不支持 CUDA，使用 CPU”；
3. 检查 MinerU Python、mineru-kit、基础/增强模型、uv、磁盘、写权限；
4. 依赖已就绪时只显示“确认并开始使用”，不再询问安装位置；
5. 缺依赖时显示缺失项，选一个安装目录（支持中文），点“开始安装并配置”。

安装过程显示：

- 第 N/6 步：uv / Python 环境 / MinerU 依赖 / 基础模型 / 增强模型 / 校验
- 正在下载：包数量、已下载 MB、百分比
- 下载完成：**正在安装：…**
- 校验：**正在校验：…**
- 全部完成弹窗

## 旧版 DOC/XLS

第一次添加 `.doc` / `.xls` 时：

1. 如果本机没有 LibreOffice，会提示自动安装（winget，约 350 MB，可能弹 UAC）；
2. 安装完成后，待转文件恢复为“等待”，重新点开始即可；
3. 也可以从菜单 **环境 → 安装旧版 DOC/XLS 支持** 手动触发。

DOCX/XLSX 不需要 LibreOffice。

## 命令行 / API

命令行和 GUI 是同一个 exe：

```bat
EIA-report-to-md.exe capabilities
EIA-report-to-md.exe convert "某报告.pdf" -o "输出目录"
EIA-report-to-md.exe convert "某文件.docx" -o "输出目录"
EIA-report-to-md.exe batch "报告目录" -o "输出目录" --pattern "" --workers 2
EIA-report-to-md.exe serve --host 0.0.0.0 --port 8765 --token 你的密钥
```

详见 [AI调用说明.md](../AI调用说明.md) 和 [API.md](API.md)。
